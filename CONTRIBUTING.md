# Правила командной работы

- **Основная ветка:** main
- **Ветки для задач:** feature/название-задачи
- **Формат коммитов:** "Добавлено: краткое описание"
- **Правило проверки:** Автор создает Pull Request. Другой участник проверяет изменения.
- **Обновление Word:** Markdown (docs/README.md) считается главным. Word (docs/report.docx) экспортируется из Markdown перед сдачей.

# Проверки и тестирование

На текущем этапе автоматизированные тесты и программная реализация могут отсутствовать. В этой папке фиксируются планируемые проверки и результаты фактически проведённых испытаний.

## План проверок
- проверка авторизации: пустые поля, неверный пароль, заблокированная учётная запись;
- проверка добавления агронома: обязательные поля и уникальность логина;
- проверка добавления записи в дневник: обязательные поля и необязательное фото;
- проверка просмотра урожайности: отсутствие данных и недостаточность данных для прогноза;
- проверка разграничения доступа между ролями «Руководитель» и «Агроном».

Результаты проверок следует добавлять только после их фактического выполнения. Не указывать тесты как пройденные, если они ещё не запускались.

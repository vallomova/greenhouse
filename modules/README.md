# Модули системы

Предполагаемые функциональные модули информационной системы:

1. **Авторизация и доступ** — вход пользователей и разграничение прав по ролям.
2. **Управление пользователями** — создание и блокировка учётных записей агрономов, закрепление теплиц.
3. **Данные датчиков и графики** — просмотр текущих показателей, выбор теплицы и периода, отображение графиков.
4. **Аналитика руководителя** — сводные показатели предприятия, сравнение эффективности теплиц, журнал действий и отчёты.
5. **Аналитика агронома** — просмотр фактической и прогнозной урожайности, сравнение показателей «до/после».
6. **Дневник наблюдений** — добавление, редактирование и поиск записей, прикрепление фотографий.

Перечень отражает функциональное проектирование из практических работ. Он не означает, что перечисленные модули уже реализованы программно.

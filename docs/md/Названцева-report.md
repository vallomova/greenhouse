# Индивидуальный отчёт — Названцева Ирина

## Выполненная часть
Сценарий SD-04 — просмотр урожайности (UC-16).

## Содержание сценария
Агроном открывает раздел урожайности, выбирает теплицу и период, запускает построение отчёта. Система получает данные о микроклимате и урожае, рассчитывает прогнозную урожайность и отображает график факта и прогноза со сводными показателями.

## Альтернативные потоки
- A1: нет данных за период — выводится сообщение «Нет данных за выбранный период».
- A2: недостаточно данных для прогноза — отображается только фактическая урожайность.

## Предусловие и постусловие
Предусловие: агроном авторизован, есть закреплённые теплицы и данные за период.
Постусловие успешного сценария: агроном получил график факт/прогноз и сводные показатели.

## Связь с требованиями
В полной таблице соответствия ПЗ №3 сценарий связан с ФТ-08 «Аналитика урожайности» и UC-16.

# Программная часть проекта

Папка предназначена для материалов программной реализации системы мониторинга теплиц.

- `src/` — исходный код приложения;
- `docs/` — документация, относящаяся к программной реализации.

На текущем этапе репозиторий содержит материалы учебного проектирования. Исходный код добавляется по мере реализации. Пустые каталоги сохраняются в Git с помощью файлов `.gitkeep`.
